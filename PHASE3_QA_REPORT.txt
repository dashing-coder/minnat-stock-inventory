Additional hardening:
- Duplicate batch numbers per warehouse/product are blocked.
- Expired batches are not issued from tracked batch stock.
- Loan interest payment cannot exceed remaining scheduled interest.
- Existing stock is initialized into cost layers during migration.
- Dashboard stock value follows FIFO/Weighted Average valuation.
- Production-style MySQL purchase-item unique index names are handled dynamically by the migration.

Environment limitation:
The validation container provides PDO core but no PDO MySQL driver and no DOM extension. Therefore the migration could not be executed against a live MySQL database here, and `php artisan view:cache` is unavailable in this container. Migration source and routes were statically validated, while every Blade template was compiled directly with Laravel BladeCompiler and the generated PHP was linted.

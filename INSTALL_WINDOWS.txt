WINDOWS INSTALL — STEP 1–14 FINAL FIX/QA
========================================

Fresh SQLite setup
------------------
1. Extract this ZIP.
2. Copy .env.sqlite.example to .env.
3. Set DB_DATABASE to the absolute Windows path of database/database.sqlite.
4. Open Terminal/PowerShell in the project folder and run:

   composer install
   php artisan key:generate
   php artisan optimize:clear
   php artisan permission:cache-reset
   php artisan serve

Existing Step 1–14 project
--------------------------
1. Back up your database and project.
2. Replace project files with this release.
3. Run:

   php artisan db:seed --class=RolePermissionSeeder
   php artisan optimize:clear
   php artisan permission:cache-reset

4. Log out and log back in.
5. Hard refresh the browser with Ctrl+F5.

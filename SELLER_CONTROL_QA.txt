M/S Afrin Traders ERP - Seller Control Release QA
Date: 2026-09-28

Implemented client requirements
--------------------------------
1. Admin/Super Admin retain full permission control, including settings.edit.
2. Total Cash is calculated only for Admin/Super Admin dashboard requests and is not passed to other roles.
3. Dedicated Seller role added with only:
   - sales.view
   - sales.create
   - sales.post
   - customer_payments.view
   - customer_payments.create
4. Seller sales list is scoped server-side to authenticated Seller + current date.
5. Seller receipt list is scoped server-side to authenticated Seller + current date.
6. Seller cannot backdate/future-date sales or receipt transactions.
7. Seller cannot access another seller's sale through a direct URL.
8. Seller receipts must reference the Seller's own posted sale.
9. Seller ID (SEL-xxxxx) is generated automatically when the Seller role is assigned.
10. Seller dashboard includes Today Sales, Today Cash, Today Receipts, Today Due, Outstanding Due, Sales References, and transaction records.
11. Admin Seller Accounts page supports per-seller daily accounting records and date selection.
12. English + Bangla translation strings added for the Seller workflow.

Runtime test limitation in this build environment
-------------------------------------------------
The container PHP runtime is missing dom, mbstring, xmlwriter and PDO SQLite extensions, so PHPUnit / full Laravel database HTTP tests could not be executed here. A regression test file is included at tests/Feature/SellerAccessControlTest.php for execution on the deployment server or normal development environment.
